  수산나디자인  견적서 자동화 프로그램  |  사용법 안내
══════════════════════════════════════════════════════════════

【 이 프로그램이 하는 일 】
────────────────────────────────────────────────────────────
makeList.xlsx에 지점 목록을 입력하면,
지점별로 견적서(Excel)와 사진 PPT를 자동으로 만들어 주는 프로그램입니다.

  예) 관저점, 유성점, 세종점 → 각각 폴더 + Excel + PPT 자동 생성

생성되는 파일:
  - 견적서/관저점/TCL_관저점.xlsx   ← 견적서 엑셀
  - 견적서/관저점/TCL_관저점.pptx   ← 시공 사진 PPT
  - 견적서/관저점/TCL_관저점.png    ← PPT를 이미지로 변환한 파일 (선택)


══════════════════════════════════════════════════════════════
  【 폴더 구조 】
══════════════════════════════════════════════════════════════

견적서_자동화/
  ├─ 실행하기.bat          ← ★ 이 파일을 더블클릭해서 실행
  ├─ makeList.xlsx         ← ★ 지점 목록 입력 파일
  │
  ├─ 양식/
  │    ├─ 견적서양식_조명.xlsx     ← 조명 견적서 양식 (건드리지 마세요)
  │    ├─ 견적서양식_비조명.xlsx   ← 비조명 견적서 양식 (건드리지 마세요)
  │    └─ 사진폼.pptx              ← PPT 슬라이드 양식 (건드리지 마세요)
  │
  ├─ 사진/
  │    ├─ 관저점/
  │    │    ├─ 시공전/   ← 시공 전 사진 넣는 폴더
  │    │    ├─ 시공중/   ← 시공 중 사진 넣는 폴더
  │    │    └─ 시공후/   ← 시공 후 사진 넣는 폴더
  │    └─ (다른 지점들...)
  │
  └─ 견적서/              ← ★ 결과물이 여기 저장됨 (자동 생성)
       └─ 관저점/
            ├─ TCL_관저점.xlsx
            ├─ TCL_관저점.pptx
            └─ TCL_관저점.png


══════════════════════════════════════════════════════════════
  【 처음 사용할 때 순서 】
══════════════════════════════════════════════════════════════

Step 1.  makeList.xlsx 작성
─────────────────────────────
  makeList.xlsx 파일을 열어서 아래와 같이 작성합니다.

    A열 (지점명) | B열 (날짜)       | C열 (조명 구분)
    ─────────────────────────────────────────
    관저          | 2025-01-15       | 조명
    유성          | 2025-01-16       | 비조명
    세종          |                  | 조명

  - A열: 지점명 (예: 관저, 관저점 둘 다 가능)
  - B열: 날짜 (입력하면 견적서에 날짜 자동 입력, 비워두면 양식 날짜 유지)
  - C열: "조명" 또는 "비조명" 입력 (비워두면 조명으로 처리)

  작성 후 저장하고 닫아주세요!


Step 2.  실행하기.bat 더블클릭
─────────────────────────────
  - 처음 실행 시: 필요한 프로그램 자동 설치 (약 1~2분 소요)
  - 설치가 끝나면 파란색 프로그램 창이 뜹니다


Step 3.  리스트 적용 버튼 클릭 (처음 한 번만)
─────────────────────────────
  [🗂  리스트 적용] 버튼을 클릭하면
  makeList.xlsx의 지점 수만큼 사진 폴더를 자동으로 만들어 줍니다.

    사진/관저점/시공전/
    사진/관저점/시공중/
    사진/관저점/시공후/


Step 4.  사진 폴더에 사진 넣기
─────────────────────────────
  [📁 사진 폴더] 버튼으로 폴더를 열어서
  각 지점의 시공전 / 시공중 / 시공후 폴더에 사진을 넣어주세요.

  지원 형식: JPG, JPEG, PNG, BMP
  사진이 없는 단계는 비워두면 됩니다 (PPT에서 자동으로 비워둠)


Step 5.  견적서 만들기 버튼 클릭
─────────────────────────────
  [📋 견적서 만들기] 버튼 클릭
  → 모든 지점의 Excel 견적서 + PPT 자동 생성
  → 완료 후 결과 폴더가 자동으로 열립니다


══════════════════════════════════════════════════════════════
  【 프로그램 화면 버튼 설명 】
══════════════════════════════════════════════════════════════

  [📋 견적서 만들기]
    → makeList.xlsx 기준으로 지점별 Excel + PPT 자동 생성
    → 이미 파일이 있으면 건너뜁니다 (중복수정 체크 안 했을 때)

  [중복수정 체크박스]
    → 체크하면: 이미 있는 파일도 덮어쓰고 다시 만들기
    → 내용이 바뀌었을 때 사용

  [📁 사진 폴더]     → 사진 넣는 폴더 열기
  [📁 양식 폴더]     → Excel·PPT 양식 파일이 있는 폴더 열기
  [📂 결과 폴더]     → 완성된 견적서가 저장되는 폴더 열기

  [🗂  리스트 적용]
    → makeList.xlsx를 읽어서 지점별 사진 폴더 자동 생성
    → 이미 있는 폴더는 건드리지 않음

  [🖼  PPT → 이미지 변환]
    → 만들어진 PPT 파일을 PNG 이미지로 변환
    → Microsoft PowerPoint 또는 LibreOffice가 설치되어 있어야 함


══════════════════════════════════════════════════════════════
  【 견적서에 자동 입력되는 내용 】
══════════════════════════════════════════════════════════════

  - 날짜 (A4, B4, C4): makeList에 날짜가 있으면 자동 입력
  - 고객명 (A6): TCL일렉트로닉스코리아 (양식 그대로 유지)
  - 건명 (B9): "TCL 로고작업-관저점" 형식으로 자동 입력
  - 파일명: TCL_관저점.xlsx / TCL_관저점.pptx


══════════════════════════════════════════════════════════════
  【 PPT 사진 배치 방식 】
══════════════════════════════════════════════════════════════

  시공전 / 시공중 / 시공후 칸에 사진 수에 따라 자동 배치됩니다.

    사진 1장 → 칸 전체에 꽉 차게
    사진 2장 → 좌/우로 나눠서 배치
    사진 3장 이상 → 2열 격자로 배치

  사진은 원본 비율을 유지하며 자동으로 맞춰집니다.


══════════════════════════════════════════════════════════════
  【 자주 있는 오류와 해결 방법 】
══════════════════════════════════════════════════════════════

  ❌ "makeList.xlsx에 지점이 없습니다"
     → makeList.xlsx 열어서 A열에 지점명이 있는지 확인
     → 저장 후 닫고 다시 시도

  ❌ "파일이 열려 있어 저장 실패"
     → 생성하려는 Excel 또는 PPT 파일이 열려 있음
     → 해당 파일을 닫고 다시 시도

  ❌ "양식 파일을 찾을 수 없습니다"
     → 양식/ 폴더에 견적서양식_조명.xlsx, 견적서양식_비조명.xlsx,
       사진폼.pptx 파일이 있는지 확인

  ❌ "PPT→이미지 변환에 필요한 프로그램을 찾지 못했습니다"
     → Microsoft PowerPoint 또는 LibreOffice 설치 필요
     → LibreOffice 무료 다운로드: https://www.libreoffice.org/

  ❌ 처음 실행 시 오류
     → 실행하기.bat를 더블클릭 (직접 py 파일 실행 X)
     → 인터넷 연결 확인 후 재시도


══════════════════════════════════════════════════════════════
  【 주의사항 】
══════════════════════════════════════════════════════════════

  · makeList.xlsx, 양식 폴더 안의 파일은 임의로 이름 변경 금지
  · 프로그램 실행 중에는 관련 Excel/PPT 파일을 열어두지 마세요
  · 사진 파일 이름은 자유롭게 지정해도 됩니다
  · 폴더 이름에 '점' 이 있어도 없어도 자동으로 인식합니다
    (예: "관저" 와 "관저점" 모두 같은 지점으로 처리)
